Sito vetrina statico del collettivo artistico IANUA. Home immersiva (il portale) + pagine dedicate a spettacoli, festival e collettivo.

- Apri con Claude Code dentro questa cartella: legge `CLAUDE.md` da solo (struttura, design system, come sostituire il video).
- Testi sorgente: `CONTENUTI.md`. Cose da fare: `TODO.md`.
- Anteprima locale: `python3 -m http.server 8080` → http://localhost:8080
- Deploy: carica la cartella su un hosting statico (consigliato Netlify), `index.html` alla radice, senza `assets/video/` e `tools/`.
